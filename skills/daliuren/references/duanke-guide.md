# 断课流程（六步定法）

排盘只是取象，**断课的价值在于把课象翻译成对具体问题的具体回答**。按以下六步走，勿跳步、勿只看三传。

## 第一步：定用神（最关键）

**先确定所问之事在课中由谁代表，再看该神的处境。** 用神未定就断三传，必然泛泛而谈。

三重来源，优先级从高到低：
1. **类神**：所问之人事本身的象（见下方速查表）
2. **六亲**：以日干为我，看该神与日干的生克（财、官鬼、父母、子孙、兄弟）
3. **位置**：日干（我、外事）／日支（家宅、对方、内事）／初传（事之始）

用神应以三传中所现者为重，四课次之，仅在天盘者最轻。用神若落空亡、入墓、被克，事多虚耗难成。

## 第二步：审干支与四课

- **日干为我**，干上神即「我目前的处境／对方对我的态度」；干阴课为我之内情。
- **日支为宅、为对方、为事之根基**，支上神即「环境、对方状态」。
- 干支上下相生 → 和顺；相克 → 有阻；上克下（外来压制）与下贼上（内部起衅）意义不同。
- **看内外**：一二课为内（我方、近事），三四课为外（他方、远事）。
- **贼克之处即矛盾焦点**，是断事最先着眼处。

## 第三步：论三传

| 传 | 门 | 主 |
|---|---|---|
| 初传 | 发端门 | 事之起因、当前主要动机、事态性质 |
| 中传 | 移易门 | 过程、转折、中途变化与阻碍 |
| 末传 | 归计门 | 结局、归宿、最终成败 |

- 三传递生 → 事顺而有人助；递克 → 步步受阻。
- 末传生日干或为日干之财官而不空 → 结果为吉；末传克日干、落空、入墓 → 结果不佳。
- 初传吉而末传凶 → 始善终恶；初凶末吉 → 先难后易。
- **末传定成败，中传定难易，初传定性质。**

**常见三传格局**：

| 格局 | 象义 |
|---|---|
| 进茹（连行顺） | 事势渐进，宜进取；若空亡则虚进 |
| 退茹（连行逆） | 事势退缩，宜守不宜进 |
| 三合成局 | 众力合聚，事有结党、合作、缠绵之象 |
| 递生 | 层层相助，或层层脱耗（视方向） |
| 递克 | 连遭压制，阻力重重 |
| 三传一神（独足） | 事不能移动，反复费力 |
| 空亡发用 | 起头即虚，事多不实、有名无实 |
| 驿马发用 | 主动、走动、变迁、远行 |
| 墓神发用 | 事晦暗不明、闭塞、拖延 |
| 丁马入传 | 静中有动、催促、事有转机 |

## 第四步：参天将

天将定**事之性质与人物身份**，不单独定吉凶——须看所乘之神与日干的关系。

| 天将 | 类象 |
|---|---|
| 贵人 | 尊长、上级、官员、贵助；乘旺则得力 |
| 螣蛇 | 惊恐、怪异、虚讶、火扰 |
| 朱雀 | 文书、口舌、消息、词讼、火 |
| 六合 | 婚姻、交易、中介、和合、胎孕 |
| 勾陈 | 争斗、纠缠、田土、牵连、拘系 |
| 青龙 | 财喜、酒食、官职、生发之事 |
| 天空 | 虚诈、欺妄、奴仆、不实之言 |
| 白虎 | 疾病、丧亡、道路、凶险、血光 |
| 太常 | 衣食、宴乐、财帛、平和之事 |
| 玄武 | 盗贼、遗失、暗昧、隐私、阴谋 |
| 太阴 | 阴私、隐匿、女子、暗中之事 |
| 天后 | 妇女、婚恋、后妃、私情 |

吉将乘吉神生日干 → 助力显；凶将乘凶神克日干 → 祸患明。吉将若落空亡则助力不实。

## 第五步：判旺衰（定力度）

**吉凶方向由神将生克定，力度大小由旺衰定。** 前四步得出方向后，必须判旺衰才能说清「有多吉、有多凶」。核心口诀：**壬课喜旺忌衰——凶神旺则凶，吉神旺则吉；休囚死则吉不真、凶也减力。**

### 四季旺相休囚死

以**月令**（节气月建）为参照：

| 季节 | 旺 | 相 | 休 | 囚 | 死 |
|---|---|---|---|---|---|
| 春（寅卯辰） | 木 | 火 | 水 | 金 | 土 |
| 夏（巳午未） | 火 | 土 | 木 | 水 | 金 |
| 秋（申酉戌） | 金 | 水 | 土 | 火 | 木 |
| 冬（亥子丑） | 水 | 木 | 金 | 土 | 火 |

推法：与月令同者旺，月令所生者相，生月令者休，克月令者囚，月令所克者死。
另：**土旺四季**，辰戌丑未月土亦作旺论。

### 用神旺衰的断法

- **旺、相**：有力。吉则更吉，凶则更凶，事速而大。
- **休、囚、死**：无力。吉不真、凶减力，事迟而小。
- 古法直断：用神得**死气**者为**绝灭**，得**囚气**者为**败坏**，得**休气**者亦为败坏。
- 旺衰与空亡叠加最忌：**用神旺而落空**，是有力而无着；**用神衰又落空**，则基本无望。

### 日干旺衰：全盘的调节器

日干是课传的太极点，其旺衰调节全盘吉凶力度：**课传凶而日干旺，可减凶力；课传吉而日干旺，则加其吉。** 三项合判：

1. **天时**——日干五行在月令下的旺相休囚死
2. **地利**——日干寄宫之上神对日干是生助、还是克制
3. **人和**——三传中有无生助日干者；三传皆克则失人和

三者俱得为旺，俱失为弱。脚本已自动输出这三项与总评，直接引用即可。

### 表述示例

不要写「财爻有力」，要写：**「三传辰丑戌俱为妻财，然申月土居休气，财多而无力，古法所谓得休气者为败坏」**——把月令、状态、古法依据一并说清。

## 第六步：查空亡神煞与年命

- **旬空**：所落之神事多虚、不实、无着。凶神落空反为解；吉神落空则吉不至。
- **入墓**：昏晦、闭塞、被困、隐藏。
- **驿马**：动、行、变迁。**丁神**：催促、动摇。
- **日禄**：财禄、俸给。**羊刃**：刑伤、锐利、争斗。
- **咸池**：情色、私情。
- **年命（本命、行年）**：占者自身之定盘星。课凶而年命上神吉、能解救者，事有转机；课吉而年命受克，则吉难受用。**凡断吉凶成败，必参年命。**

## 第七步：应期

按优先级择用：
1. 用神所乘之神的**地支值日／值月**
2. **末传**所对应之支的时日
3. 三传中**驿马、丁神**所在
4. 用神与日干**相合、相冲**之日
5. 空亡者出空之日

顺行之课应期近而顺，逆行之课应期迟而反复。伏吟主迟滞待时，返吟主反复速变。

| 占题 | 用神 |
|---|---|
| 求财 | 妻财爻、青龙、太常；财旺不空且生日干为得 |
| 求职求官 | 官鬼、贵人、朱雀（文书）；喜生日干、忌空墓 |
| 官司诉讼 | 朱雀（词讼）、勾陈（纠缠）、白虎（刑）；日干强弱定胜负 |
| 婚姻 | 六合、天后、太阴；男看日干女看日支，看干支生克与合冲 |
| 疾病 | 白虎、日支（病人）、官鬼（病症）；忌末传入墓、干墓乘虎 |
| 失物 | 玄武（盗）、初传（失处）；看玄武所乘之神方位 |
| 行人 | 日支上神、驿马；马入传主至，伏吟主不动 |
| 出行 | 驿马、初传；返吟主往返，伏吟主不成 |
| 考试 | 朱雀、贵人、日禄；喜生日干、忌空 |

## 常见课象组合速判

- **伏吟**：静、伏、屈不得伸、静中思动；行人不至、出行不成、失物在近处；须待驿马丁神方能动。
- **返吟**：动摇不宁、往返反复、来去无常、两地系心、事从下起、亲情无始终；利于重提旧事。
- **元首课**（上克下）：事体顺理，尊长压制，多主正大之事，凡事有成。
- **重审课**（下贼上）：事起卑下，内部生变，须再三审慎。
- **知一课**：事有双岐，两者择一，祸从近处来，失物在邻近。
- **涉害课**：历尽艰险方得结果，阻碍重重，宜见机而作。
- **昴星课**：事暧昧不明、忧疑、进退失据；虎视主惊，冬蛇掩目主蔽塞不见。
- **别责·八专**：事有重叠双歧，或不正、暧昧、私情牵连。
- **独足课**：事不能移动，极其费力，多脱耗。

## 输出与表述要求

- **必须先给结论，再给依据**，不要罗列课象让用户自己解读。
- 依据须落到具体神将：说「末传亥水乘白虎克日干」，而非「课象不吉」。
- 课象矛盾时如实说明「此课象吉凶交杂」，并指出转机条件，不要强行给单一答案。
- **必须声明**：术数属传统文化范畴，无科学依据，仅供文化参考与决策思路启发，不可替代医疗、法律、金融等专业意见；涉及疾病、诉讼、投资等重大事项，应明确建议寻求专业帮助。
- 不作恐吓性表述（如断人生死、绝症、必败），不诱导迷信消费。
