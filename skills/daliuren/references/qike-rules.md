## 一、三要素：占时、月将、日干支

| 要素 | 取法 | 说明 |
|---|---|---|
| 占时 | 求测当下的时辰（非事发时辰） | 23:00–00:59 为子时；脚本默认 23 时后日干支进位次日 |
| 月将 | 太阳所躔宫位，**过中气才换将** | 非按农历月，必须依节气 |
| 日干支 | 六十甲子 | 换日以子时为界（可用 `--no-night-advance` 改 0 时换日） |

### 正时与活时（报时）

| 取时法 | 做法 | 适用 |
|---|---|---|
| **正时**（真时） | 以求测当下的时辰为占时 | 默认主流用法；自己忽起一念要占某事 |
| **活时**（报时、抓数、抽签） | 由问事人随口报一时辰，或报数、抽签、翻书页取数转为地支 | 一个时辰内要问多件事；一时辰内来人众多；久疑不决之事 |

**为何需要活时**：一个时辰长达两小时，正时起课在这两小时内所得课式**完全相同**。古法明言「一般以来人求占时间定为正时，如一个时辰内来人众多，正时不够运用，方可取用活时法」；亦有「第一个来人用正时，其余用活时更为对应」之说。

**关键规矩**：报时**只换占时**，日干支与月将均不变。报数转地支：子1、丑2、寅3……亥12，超过 12 则减 12 或取余。

脚本用法：`--baoshi <地支>`，输出会标注「（报时）」以区别正时。

## 二、天地盘

地盘十二宫固定不动（子丑寅卯……按固定方位）。**月将加占时**：把月将放到地盘占时宫上，其余十一神顺次排布，即成天盘。

- 偏移量 = 月将 − 占时（模 12）
- 偏移为 0 → **伏吟盘**（将与时同）
- 偏移为 6 → **返吟盘**（将与时相冲）

看每课上下五行关系：**下克上为「贼」（重）**，**上克下为「克」（轻）**。

## 四、九宗门取三传

判定顺序（脚本即按此实现）：

```
伏吟盘 ─→ 有克依贼克法 / 无克用伏吟法（自任·自信·杜传）
返吟盘 ─→ 有克依贼克法（无依）/ 无克取驿马（井栏射·无亲）
常  盘 ─→ ①贼克 → ②比用 → ③涉害 → ④八专 → ⑤遥克 → ⑥别责 → ⑦昴星
```

> 关键顺序坑：**四课不全（只三课）者取别责，不取昴星**；**干支同位（八专日）无克时取八专，不再取遥克**。

### 1. 贼克法
只一处下贼上 → 取之，为**重审课**；无下贼上而只一处上克下 → 取之，为**元首课**。
中传 = 初传在天盘所乘之神；末传 = 中传所乘之神（下同，称「顺取」）。

### 2. 比用法
克处有两处以上，取与日干**同阴阳**者发用。
两处克 = 知一课；三处 = 度厄课；四处下贼上 = 绝嗣课，四处上克下 = 无禄课。

### 3. 涉害法
俱比或俱不比时用。各克神从其所落地盘宫**顺行归本家**，途中所历地盘之支及寄宫天干中，与之构成相克者计数，**受克最深者发用**。

- 深浅相等 → 取乘**四孟**（寅申巳亥）者，为**见机课**
- 无孟 → 取乘**四仲**（子午卯酉）者，为**察微课**
- 仍相等 → **复等课**，刚（阳）日取干上神，柔（阴）日取支上神

### 4. 遥克法
四课无上下克时。先取**上神遥克日干**者发用 → **蒿矢课**；无则取**日干遥克之上神** → **弹射课**。多者仍依比用、涉害之法择一。

### 5. 昴星法
四课全备、无上下克亦无遥克。
- 阳日：取**地盘酉宫之上神**发用，中传支上神，末传干上神 → **虎视课**
- 阴日：取**天盘酉之下神**发用，中传干上神，末传支上神 → **冬蛇掩目课**

### 6. 别责法
四课不全（仅三课）、无克无遥克。
- 阳日：取日干**六合之干**的寄宫上神发用（干合：甲己、乙庚、丙辛、丁壬、戊癸）
- 阴日：取日支**三合前一位**发用
- 中末传俱取干上神。又名**芜淫课**

### 7. 八专法
干支同位（甲寅、乙卯之属，实为甲寅、丁未、己未、庚申、癸丑五日）且无克。
- 阳日：干上神在天盘**顺数三位**（含本位）发用
- 阴日：第四课（支阴）上神**逆数三位**发用
- 中末传俱取干上神。三传同一神者为**独足课**，否则**帷簿不修课**

### 8. 伏吟法
有克照贼克法取用（癸丑之属为**不虞课**）。无克则：
- 阳日取干上神 → **自任课**；阴日取支上神 → **自信课**
- 中传取初传**所刑**，末传取中传**所刑**
- 初传若为**自刑**（辰午酉亥）→ 中传改取另一宫上神（发用于干上则取支上，反之取干上），为**杜传课**
- 中传又自刑 → 末传取其**冲神**

三刑：子卯相刑、寅巳申相刑、丑戌未相刑、辰午酉亥自刑。

### 9. 返吟法
有克照贼克法取用 → **无依课**。
丁丑、己丑、辛丑、丁未、己未、辛未六日四课无克 → 取**日驿马**发用（丑日马亥、未日马巳），中传支上神，末传干上神 → **井栏射（无亲课）**。

## 六、遁干与旬空

- **旬空**：日干支所在旬中，无天干可配的两个地支。
- **遁干**：由旬首起，顺配天干于地支，得各神所遁天干。三传带遁干方能细看生克。
- **旬丁**：旬首地支 +3 位，为动摇催促之神。
