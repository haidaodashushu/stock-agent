# 大六壬

## 核心流程

**第一步：排盘（必须用脚本，禁止手推）**

排盘涉及月将过宫、九宗门三十余种取用分支、天将顺逆，手工推演极易出错。一律调用脚本：

```bash
# 按当前时间起课（正时）
python3 scripts/liuren.py --now

# 按指定时间起课（自动定日干支、月将、时支、昼夜、月令）
python3 scripts/liuren.py --datetime "2026-08-19 21:30"

# 报时（活时）起课：日干支与月将不动，只以所报时辰为占时
python3 scripts/liuren.py --now --baoshi 申

# 复盘古例：直接指定三要素，不依赖历法（--month 可补月令以判旺衰）
python3 scripts/liuren.py --day-gz 丁卯 --general 亥 --hour 丑 --month 寅

# 带年命行年（断吉凶成败必参年命）
python3 scripts/liuren.py --now --benming 子 --xingnian 寅

# 结构化输出，便于精确引用课象字段
python3 scripts/liuren.py --now --json
```

常用参数：`--tz` 时区（默认 +8）；`--day`/`--night` 强制昼夜贵人；`--hour` 单独指定占时地支；`--month` 指定月令（影响旺衰）；`--no-night-advance` 改为 0 时换日。

**正时与报时的选择**：默认用正时（求测当下之时）。以下情形改用 `--baoshi`——同一时辰内要问多件事（正时会得到完全相同的盘，无法分别断）、久疑不决之事、或用户主动报了一个时辰/数字。报时只换占时，日干支与月将不变。

**用户未提供占时则默认用 `--now`**（六壬以求测当下之时起课，非事发之时）。若用户报的是农历或只报事发时间，须先确认求测时间。

**第二步：断课**

排盘后**必读 `references/duanke-guide.md`**，按其六步定法断事：定用神 → 审干支四课 → 论三传 → 参天将 → 查空亡神煞年命 → 定应期。

关键要求：
- **先定用神再断事**。所问之事在课中由哪个神代表，决定了整个判断的落点；用神未定就泛论三传，等于没断。
- **定了用神必判其旺衰**。旺衰不改变吉凶方向，只放大或衰减力度——「凶神旺则凶，吉神旺则吉」；休囚死则「吉不真、凶也减力」。用神得死气为绝灭、囚气为败坏。同一课式在不同月令下力度不同，不可只报吉凶不报力度。
- **日干旺衰是全盘的调节器**。课传凶而日干旺可减凶力，课传吉而日干旺则加吉。脚本已给出天时（月令）、地利（寄宫上神）、人和（三传生助）三项及总评，须一并纳入判断。
- 结论必须落到具体神将，如「末传亥水乘白虎克日干，且值休气无力」，不可只说「课象不利」。
- 三传为骨（初传定性质、中传定难易、末传定成败），天将为象（定人物身份与事之性质），旺衰定力度，神煞年命为参。

**第三步：核对（结果可疑时）**

对取用有疑、或用户质疑三传时，读 `references/qike-rules.md` 核对规则，并跑回归测试确认引擎无恙：

```bash
python3 scripts/test_cases.py   # 21 例古籍课例，应全数通过
```

## 输出格式

先给排盘图（直接用脚本的文本盘），再给判断。判断部分的结构：

1. **课体与总象**——课名、盘式（常盘/伏吟/返吟）、一句话定调
2. **用神所在**——所问之事由何神代表，其处境如何
3. **分层判断**——起因、过程、结果各自的依据
4. **应期**
5. **可为之处**——课中的转机条件（如出空、待马、年命救应）

## 边界与声明

- **每次断课必须声明**：术数属传统文化范畴，无科学依据，仅供文化参考与思路启发。
- 涉及疾病、诉讼、投资、婚姻等重大事项，明确建议寻求专业意见，不以课象替代专业判断。
- 不断生死、绝症、必败等恐吓性结论；课象吉凶交杂时如实说明，不强行给单一答案。
- 用户仅问规则、课体、术语（如「什么是涉害课」）时，直接依 `references/qike-rules.md` 讲解，无需排盘。

## 文件说明

- `scripts/liuren.py`——排盘引擎，含历法（日干支、太阳过宫定月将）与九宗门全部取用分支
- `scripts/test_cases.py`——21 例古籍课例回归测试，覆盖九宗门各法
- `references/qike-rules.md`——起课规则与基础表，用于核对与讲解
- `references/duanke-guide.md`——断课六步定法、用神速查、课象速判、表述要求
