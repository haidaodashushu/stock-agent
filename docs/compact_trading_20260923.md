# 操盘输入与输出精简（2026-09-23）

现有操盘反复传入公司/趋势详细讨论、选股历史，并为大量未交易股票重写完整计划及四维评价。本次保持逐股检查和现有交易校验，将默认输入改为核心证据，并为未变化的 hold/watch 增加受约束的短格式。

## 行为

- `stock_evidence` 默认 `view="brief"`：保留核心研究论据、完整风险和更新条件、当前量价/资金流/新闻、账户与持仓信息、原交易计划（含原 thesis），省略重复选股/上次决策叙述与空字段。尚未完成研究的股票保留公司/趋势讨论及选股上下文。
- `view="financials"` 只补财务字段；`view="full"` 获取完整证据。旧 `include_research_details=true` 仍返回完整视图。输出字段路径保持兼容；缺省字段不能理解为0或没有风险。
- MCP返回紧凑JSON文本，关闭自动结构化副本，避免缩进及二次编码。
- 短格式仍明确提交 action、confidence、本轮 reason/risk、四维等级及快照引用。只允许持仓 hold、非持仓 watch，原计划及等级必须未变；服务端还原完整记录后运行原有校验。
- 引用绑定账户、股票、as_of、完整原计划、研究版本和旧等级。新有效事件、结构失效、研究变化、研究未就绪或无匹配历史记录时不开放复用。原交易动作和历史确认项不继承，也不继承重新买入资格。
- 买卖、研究更新、计划/评级变化仍提交完整行。所有应研究股票及持仓仍必须覆盖；成交逻辑、T+1可卖量、调度与事件频率不变。
