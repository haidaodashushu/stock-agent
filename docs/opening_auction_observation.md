# 开盘集合竞价观察与候选补充

先保存完整原始事实，再从固定战略赛道池生成少量、短时、不可直接买入的观察候选，用来补充盘前固定候选。

## 采集范围与时点

- 范围：固定战略赛道100股。
- `09:19:50`：可撤单阶段末期，腾讯原始五档快照。
- `09:24:50`：不可撤单阶段末期，腾讯原始五档快照。
- `09:25:05`：最终竞价后的腾讯快照。
- `09:27`：问财最终竞价匹配价、涨幅、匹配量/金额、带符号的未匹配量/金额和异动说明。

问财不提供可靠的历史9:20/9:24过程值：即使查询中写明具体时点，返回的仍是9:25最终字段。因此过程数据
只保留腾讯原始值，未验证前不把盘口档位量解释成“匹配量”或“未匹配量”。

## 数据与交易边界

- 原始事实表：`opening_auction_runs`、`opening_auction_snapshots`、`opening_auction_final`。
- 派生候选表：`opening_auction_watch_candidates`，包含规则版本、生成时间、失效时间和完整证据。
- 腾讯成交量、成交额及五档数量以 `raw` 命名，第一阶段不假定单位或竞价语义。
- 问财返回列明确标注股和元，分别保存为 `*_shares`、`*_yuan`。
- `unmatched_*_signed` 保留供应商正负号，待样本验证买卖方向后再命名。
- 竞价候选的 `buy_eligible` 固定为 `false`，只扩大操盘模型必须分析的范围，不触发买入。
- 候选板最多12只。竞价或盘中雷达出现新股票时，为其保留动态席位，并从当前决策范围移出盘前排序最弱者；
  `screen_records` 历史结果不被删除。
- 竞价观察在10:00失效；开盘后的实时量价满足正常盘中雷达规则时，才能作为可交易候选重新进入。

## 当前观察规则（v1）

同时满足以下条件时，按竞价匹配金额排序，最多保留3只：

- 问财竞价评级为“看多”；
- 最终竞价涨幅在0.5%到4%之间，回避明显低开和过度高开；
- `09:19:50`腾讯指示价到最终匹配价至少增强0.5%；
- 属于固定战略赛道池，且不是ST。

竞价异动类型、未匹配金额方向和未经验证的盘口原始量，不作为硬触发条件。

## 观察检查

```bash
.venv/bin/python scripts/report_opening_auction_observations.py --days 5 --top 20
```

继续检查三个时点和最终字段的覆盖率，并按日评估观察候选开盘后的有效性。样本扩大前不得把v1规则解释为
稳定收益模型；它只是候选发现器。
