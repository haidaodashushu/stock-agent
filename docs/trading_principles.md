# 操盘核心原则

## 低位多看逻辑变化，高位多看趋势量价

这是本系统选股、模拟操盘、实盘操盘的核心判断框架。

试验分支进一步把入场拆成两条互补路线：低中位的 `early_start` 持续观察趋势萌芽，高位的
`strong_continuation` 追随经过价格保持和承接验证的主升趋势。高低位置都不是单独的买卖理由。

### 1. 低位：优先看逻辑变化

低位股票的核心不是追求已经走出来的强趋势，而是识别“逻辑是否发生变化”。注意：静态属于某个概念，只能叫“主线匹配”，不能直接叫“逻辑变化”。

- 是否出现新的产业政策、订单、产品、技术路线、价格周期、景气变化；
- 是否进入十五五科技、AI算力、高端制造等主线；
- 是否从无人关注转为有资金试盘、放量异动、缩量洗盘；
- 是否基本面/题材逻辑比过去更强，而价格仍在相对低位。

分层口径：

- 主线匹配：属于十五五、AI算力、低空经济、国产替代等方向，只能小幅加分。
- 弱逻辑变化：近期新闻、热词、板块异动出现，但还缺资金/量价确认。
- 中逻辑变化：行业/公司有明确增量，且技术面开始确认。
- 强逻辑变化：政策/订单/业绩/产业景气变化 + 资金确认 + 低位启动或高位强承接。

低位候选可以给“逻辑变化”更高权重，但不能忽略底线：

- 不能是明显退潮/破位下跌；
- 最好出现初步止跌、金叉、放量试盘、缩量企稳等确认；
- 只因便宜而没有逻辑变化，不应重仓。

### 2. 高位：优先看趋势量价

高位股票不能只听故事，必须用趋势和量价验证：

- 趋势是否仍保持 5/10/20 日均线正向；
- 拉升是否放量、回调是否缩量；
- 是否出现高位巨量不涨、长上影、放量滞涨、MACD/量价背离；
- 是否跌破 5/10 日线或关键平台；
- 尾盘是否有资金承接，而不是出货型拉高。

高位如果逻辑很好但量价坏了，应降权、减仓或回避；高位只有趋势量价继续确认，才允许持有或小幅加仓。

### 3. 选股落地

- 低位 + 主线匹配 + 初步技术确认：可进入观察池。
- 低位 + 逻辑变化 + 初步技术确认：可进入候选/观察池。
- 低位 + 逻辑变化 + 放量启动：可进入买入优先级。
- 高位 + 趋势良好 + 量价配合：可继续持有/跟踪。
- 高位 + 放量滞涨/长上影/跌破短均线：降权、减仓或剔除。
- 每日全市场扫描只负责新增和更新线索，不再每天清空候选记忆。
- 同一股票的准备、升温、行动、冷却和失效状态跨日保存；持续改善优先于单日绝对排名。
- 单日异动、集合竞价或盘中雷达只能触发复核，不能独立生成买点。
- 强势延续股票不因创新高机械拒绝；第一次直线急拉、巨量滞涨或突破失败不能视为有效延续。

### 4. 模拟操盘落地

- 建仓优先找低位中/强逻辑变化和趋势刚启动的标的；只有静态主线匹配的标的排在后面。
- 持仓上涨进入高位后，判断重点从“题材好不好”切换到“趋势量价是否继续支持”。
- 高位不因故事补仓，只有量价继续确认才考虑持有或小加。
- 高位量价转弱时，先保护利润，再谈逻辑。
- 组合目标为10—12只、硬上限15只。达到目标后，候选必须与最弱持仓直接比较，并同步替换或减持旧仓。
- 持仓退出不只等待价格破位；逻辑衰减、相对强度落后、行业重复和机会成本均进入组合淘汰判断。
- 连续减仓后仍未转强的低权重尾仓应清理，避免持仓数量虚假分散。

### 5. 实盘操盘落地

实盘操盘更严格：

- 低位逻辑变化不能直接建议重仓，必须至少有一个技术/量能确认；静态主线匹配不能当作实盘操盘理由。
- 高位标的不因概念热度直接建议买入，必须有趋势量价同步确认。
- 实盘资金、资金流水和持仓上限只读取本地账户配置，不在仓库中保存真实值；资金流水不计入交易收益，仍按可用现金和标的确定性控制仓位，不追高位量价不配合的票。
- 操盘建议单理由必须写清：当前属于主线匹配、弱/中/强逻辑变化，还是高位趋势量价确认。
