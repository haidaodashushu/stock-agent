# 跨日入场策略试运行

试验分支：`experiment/stateful-entry-strategy`。

## 目标

解决两个互补问题：

1. 每天重选导致低位准备股票在真正启动前消失；
2. 为避免追高而机械错过真正的强势主升。

## 本轮变化

- 全市场初筛按 `early_start` 与 `strong_continuation` 保留路线容量；
- 每次量化TOP池写入 `candidate_discovery_history`；
- `candidate_lifecycle` 跨日维护准备、升温、行动、冷却和失效；
- 每日最终选股直接进入正式候选池，候选池总数最多15只；
- 低位早期路线至少经过两个完整日K观察；
- 强势延续路线允许追高，但用突破保持、收盘承接、量能效率和派发风险区分真假强势；
- 生命周期只保留跨日观察证据，不再直接进入操盘候选；
- 固定战略观察股通过独立判断后才能晋升，竞价和盘中雷达本身不直接获得买入资格；
- 操盘理由必须说明入场路线、生命周期阶段和失效条件。

## 观察口径

分支启用后从零开始积累完整日K生命周期，不使用当前新闻和资金流反向填充历史，避免未来数据污染。建议按
交易日分段记录：

- 候选在启动前提前几天首次出现；
- preparing→warming→actionable 的晋级比例和耗时；
- early_start 与 strong_continuation 各自的买入次数、次日及3/5日结果；
- actionable 后未成交、成交和失效的原因；
- 高位追随的价格保持率、突破失败率；
- cooling/invalidated 是否能阻止后续每日选股再次误选。

模拟盘和实盘仍使用各自原账户与账本，因此试验前后收益按分支启用日期切分，不把外部入金计入交易收益。
回退到基线分支时，新表会保留但旧代码不会消费，不需要删除数据。
