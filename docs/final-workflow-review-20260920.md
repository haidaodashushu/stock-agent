一次性预热 36 只，串行分成每批 3 只，共约 274.7 秒、无请求错误。常规每轮最多刷新 3 只财务资料，成功后缓存一天，失败后至少间隔一小时；两个账户通过数据库预约避免重复刷新同一只。实时监控不调用这些接口。缓存过期或失败保留原观察时间，不伪装为刚取得的资料。主机已启用 `financial_enrichment`；提交的配置模板默认关闭，独立部署需显式启用。

[扶摇接口总览](https://fuyao.aicubes.cn/docs/api-reference/overview/)说明可能动态限流，不能据此承诺无限并发。客户端同时检查 HTTP 与业务状态码，不立即连续重试。密钥仅存主机 ignored 私有配置，权限 0600。

扶摇行情快照测试成功，但返回了周日数据就绪时间，而腾讯个股成交源时间仍为周五；因此本轮**没有**把扶摇快照接成盘中新鲜报价的兜底。[资金流](https://fuyao.aicubes.cn/docs/api-reference/capital-flow/)和[高频动向](https://fuyao.aicubes.cn/docs/api-reference/high-frequency/)页面明确标注暂未开放外部接入，不能充当分钟线/资金流备用源。其普通历史 K 线接口目前只支持日线。

## 本次修复

- 执行器整体报错或收盘跳过时，提交不得记为成功，也不得完成观察计划、研究更新或事件。保持失败待复核、不自动重放；单笔因 T+1 等被拒绝仍是有效的执行回执。
- dry-run 不进入消息发送队列，不保存新的研究/观察计划。
- 重评和新增消息的起点使用证据时间，避免模型耗时导致跳过下一个半小时，或忽略模型处理期间新入库的消息。
- 财务报告期按真实时间排序，避免 `2026A`、`2026Q1`、`20260630` 字符排序错误；未明确报告期的数值不混进本期，未知不填零。旧问财零值在操盘证据中标为不确定，新接口返回的真实零予以保留。
- 资金流请求带所需日期，无日期资金不再伪装当前日期。公司新闻列表/历史大事汇总页不触发新公告及风险事件，也不作为新政策催化。
