# 个股买入资格共享标准

本标准只回答“当前证据是否足以获得买入资格”。选股和晋升据此授予资格；账户操盘还要结合资金、持仓、
机会成本和执行约束决定是否行动。

## 数据语义

- overview 提供确定性市场分类时必须原样采用；未提供时不自行制造分类。强弱环境可以调整确认难度，但不能替代个股判断。
- 资金流只有 `status=available` 且 `source_date_verified=true` 才能作为当前独立确认；`cached` 或源日期未核验只能作背景，缺失表示未知。它表示该时点的当日累计值，不等于最近半小时持续流入。
- 板块归属、板块涨跌和轮动标签属于同一证据家族，不得重复计数。只有归属可靠且个股与板块同向时才增强结论。
- 静态题材、观察池来源、竞价身份、雷达分数和量化总分都是发现线索，不能单独授予资格。

## 证据阶段

- 夜间/盘前选股使用最新完整日线、公司、板块和资金证据判断候选资格，并把需要盘中验证的条件写入风险；
  不得假装已经看到下一交易日的竞价或盘中确认。
- 盘中晋升与账户操盘使用当前已固化的竞价、分时、VWAP 和承接证据继续确认。两阶段使用相同入场路线和失效
  逻辑，区别只来自决策时点实际可见的数据。

## 入场路线

- `early_start`：低中位趋势萌芽。需要低点企稳、波动收敛、短均线转向、上涨日量能占优、增量逻辑等多项改善；
  盘中还应看到温和放量、站上 VWAP、回踩承接或二次增强。
- `strong_continuation`：强趋势延续。重点验证多周期趋势、平台突破后的价格保持、上涨量能效率、板块共振和
  首次整理或回踩承接。涨幅、贴近日内高点、VWAP 和同一段直线拉升只能算一个价格动量事实。

## 资格判断

- ST、停牌、不可成交或关键行情缺失时不能授予资格。
- 盘中 09:30 附近样本不足时，`strong_continuation` 不能只依赖涨幅、量比、贴近高点和 VWAP；还需竞价确认、
  板块同向、可靠公司增量逻辑或此前平台承接中的至少一类独立证据。
- 从日内高点回撤 5% 以上后的单个半小时反弹默认只是修复；重新收复关键平台并稳定一个观察区间后再判断。
- 放量滞涨、长上影、反复开板、跌回突破位、利好不涨或可靠负面事件可直接否决强趋势延续。
- 分别评估正面与风险证据的强度、可靠性和持续性。一般分歧应降低置信度或继续观察；多类独立可靠证据持续
  同向时应改变资格结论，而不只是提高文字上的信心。
- 通过资格时必须给出入场路线、当前有效证据和可验证的失效条件。`early_start` 失效包括重新放量创新低或
  结构改善被证伪；`strong_continuation` 失效包括突破失败、持续失守 VWAP/平台或相对板块明显转弱。
