# 个股买入资格共享标准

本文件是观察股晋升与模拟/实盘操盘共同使用的唯一“个股是否具备买入资格”标准。晋升只判断股票本身，
不读取账户现金、持仓数量、行业仓位或替换对象；操盘在同一标准之上继续处理账户容量、机会成本和实际动作。

市场强弱由事实层按统一指数规则计算，必须原样采用 `market.regime.regime`，不得自行重新分类；模型只负责
解释该状态对当前股票的影响。市场环境决定
风险预算和确认强度，不替代个股判断：强市可以积极使用 `strong_continuation`；中性或弱市仍可参与板块共振、
价格保持和承接很强的股票，但必须提高确认要求；全市场恐慌或流动性快速恶化时，不得把少数逆势急拉解释为
安全买点。

资金流仅是可选辅助事实。只有 `status=available` 才能作为当前确认；`cached`、缺失或可靠性低只能作为背景，
不能推断为当前流入或流出。板块归属、轮动和涨跌属于同一类证据，不得重复计数；只有归属与轮动版本完整、
个股与板块同向时才能增强结论，不能单独触发买入。

只允许以下两种 `entry_route`：

- `early_start`：低中位趋势萌芽。静态题材不是买点，至少需要低点不再下移、波动收敛、短均线转向、上涨日
  量能占优、增量逻辑等多项改善；盘中还需要温和放量、站上VWAP、回踩承接或二次增强。
- `strong_continuation`：强趋势延续。不得仅因位置高或创新高机械拒绝，重点验证多周期趋势、平台突破、价格
  保持、板块共振、上涨量能效率和首次整理/回踩承接。涨幅、相对强度、贴近日内高点、VWAP和同一段直线
  拉升只能算一个价格动量事实；放量滞涨、长上影、反复开板、跌回突破位或利好不涨优先否决。

共同约束：

- ST、停牌、不可成交或关键行情缺失的股票不能获得买入资格。
- 09:30附近缺少完整半小时样本时，`strong_continuation` 不能只凭涨幅、贴近高点、量比和VWAP通过；至少还需
  最终集合竞价确认、板块同向、可靠公司增量逻辑或此前平台首次回踩承接中的一类独立证据。
- 从日内高点回撤5%以上后的单个半小时反弹，默认只是失败突破修复；只有重新收复关键平台、回撤收窄并保持
  一个完整观察区间，才可重新判断。
- `selection.logic_change.tradeable_positive=false`、板块处于 `laggard/negative` 且股价处于60日极高位置时，
  正反证据明显不对称，除非出现新的高可靠公司事实并被板块和价格保持共同确认，否则不能通过。
- 必须分别评估正面证据和风险证据的强度、可靠性与持续性。重大可靠风险可以否决；一般性分歧不自动否决，
  应通过降低置信度或继续观察表达，不能因为存在任何风险就永远不改变动作；多类可靠证据持续同向时，
  不得只提高 `confidence` 而始终不改变实际动作或资格结论。
- 买入资格结论必须写明入场路线、当前有效证据和可验证的失效条件。`early_start` 失效包括重新放量创新低或
  结构改善被证伪；`strong_continuation` 失效包括突破失败、持续不能收回VWAP/平台或相对板块明显转弱。

观察池或动态来源身份本身不加分。集合竞价和盘中雷达只负责触发评估；是否晋升、是否在正常操盘中买入，
都必须按以上同一标准使用当时已经固化的完整事实判断。
